# TO-DO Personal 0.4.47

Оформление подтверждения почты и восстановления пароля повторяет карточку входа:
фон #F7F3EE, бумага #FFFDFB, акценты #C38D9E, текст #501F3A. Слова, темы,
условие выбора русского/английского и {{ .ConfirmationURL }} сохранены.

Оба тела шаблонов повторно открыты в hosted Supabase и сверены с файлами.
SMTP включён, прежний сервер smtp.resend.com и имя TO-DO Personal сохранены.

Приложение теперь различает ограничения отправки, отказ сервиса, серверный сбой
и отсутствие соединения. Сбой SMTP/сервера больше не предлагается исправить
проверкой интернета. Одинаковая обработка при восстановлении с экрана входа
и из настроек аккаунта. Нет автоматической повторной отправки писем.

Исходная недоставка пока не воспроизведена: в проверенном интервале журналов
после смены шаблонов отсутствуют запросы /recover, поэтому причина не установлена.
Проверка настоящей отправки требует согласованного получателя. Получение письма
и физический Android нельзя считать проверенными по одним автоматическим тестам.

Android: com.m1strell.todopersonal, versionCode 51. Прежний ключ подписи.

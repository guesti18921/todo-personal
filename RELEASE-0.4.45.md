# 0.4.45 — возврат из восстановления пароля и сведения о данных

- На Android основная кнопка после смены пароля открывает установленное приложение.
  Веб-версия остаётся отдельной явной ссылкой; автоматического перехода в неё нет.
- Ссылка возврата не содержит Auth-токенов. Холодный/тёплый запуск показывает вход;
  открытый аккаунт и несохранённый редактор не меняются.
- Политика RU/EN описывает browser push, локальные напоминания, JSON-копии и удаление.
- Документы выпуска и подписи обновлены. Версия Android: code 49.
- Автоматические проверки покрывают маршруты браузера, native bridge и данные.
  Физическое открытие установленного APK системой Android требует проверки телефона.

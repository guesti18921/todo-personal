# TO-DO Personal — материалы выпуска 0.4.45

Проверка: 20 октября 2026. Распространение: веб и прямой подписанный APK.

## Описание на русском

Короткое: Личный блокнот с задачами, заметками, напоминаниями и синхронизацией.

TO-DO Personal помогает сохранять мысли и планы в одном месте. Создавайте задачи
и заметки, задавайте сроки, закрепляйте важное и находите записи поиском.
Блокнот хранит локальную копию для работы без интернета и синхронизирует записи
через аккаунт при подключении. Android поддерживает локальные напоминания;
веб-версия — дополнительные браузерные push-уведомления по вашему разрешению.
Вход доступен через Google или электронную почту. Интерфейс — русский и английский.
Можно экспортировать записи в JSON и импортировать выбранную резервную копию.
Доступны удаление аккаунта в настройках и запрос удаления без приложения.

Не обещать гарантированную доставку уведомлений при любых настройках системы,
сквозное шифрование, неограниченное облако или автоматический перенос черновиков.

## English listing

Short: Personal tasks, notes, reminders and account synchronization.

Keep ideas and plans in one notebook. Create tasks and notes, set due dates,
pin important entries and search your notebook. An on-device copy supports
offline work and synchronizes through your account when connected. Android
supports local reminders; the web version offers optional browser push.
Sign in with Google or email. Russian and English interfaces are available.
Export entries as JSON and import a selected backup. Delete your account in
Settings or request deletion without the app.

## Изображения для описания

Использовать текущий 0.4.45 без личных данных: экран входа; задачи с несколькими
сроками; заметка; экран сохранения и копий. Демонстрационный интерфейс не выдавать
за фактический APK. Скриншоты реального устройства ещё не подтверждены.

## Сохранённые материалы и границы проверки

Исходники — публичный GitHub guesti18921/todo-personal, точный коммит закреплён
в android-signed.yml. Подписанные APK/AAB сохраняются отдельно с SHA-256 и
отпечатком постоянного сертификата. Ключ подписи не входит в пользовательский
архив и не раскрывается. Его отдельная резервная копия у владельца не проверена;
наличие секрета сборки не является подтверждением такой копии.

Остаются известными ограничения бесплатной конфигурации: не включена проверка
паролей по утечкам; GitHub Pages не предоставляет необходимой настройки защитных
HTTP-заголовков. CSP в приложении сохранена. Платные сервисы не подключались.
Физическое Android-устройство недоступно для проверки системного открытия ссылки.
